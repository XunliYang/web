Overview

When a customer calls in with "no internet for two days" or "YouTube is slow", OpenAN orchestrates the right agents end-to-end — billing, CDN, RAN, and vendor-specific fault agents — and hands off to a human expert only when needed. This demonstrates the power of multi-agent collaboration in telecom operations.

Business Challenge

  • High volume of customer complaints requiring manual triage and routing
  • Long resolution times due to siloed systems and lack of cross-domain visibility
  • Inconsistent diagnosis across different complaint types and network domains
  • Expert NOC staff overwhelmed with routine issues that could be automated
  • No unified workflow connecting call center, OSS systems, and network operations

Solution Architecture

The Home Broadband Complaint Handling Agent recalls a workflow from the Orchestration Center, retrieves the matching agents from the Registry Center, and coordinates them over A2A-T.

Different complaints trigger different workflows: a billing issue invokes the customer-care and billing agents; a CDN issue invokes customer-care, the CDN agent, and a vendor FAN agent.

Workflow Steps

  • Intent capture — Call center receives the customer complaint and forwards intent to the Complaint Handling Agent
  • Workflow recall — The Orchestration Center selects the workflow that matches the complaint type
  • Agent retrieval — The Registry Center returns matching agent cards (customer care, billing, CDN, vendor FAN, etc.)
  • Multi-agent execution — Agents collaborate over A2A-T to diagnose and resolve the issue
  • Expert handoff — When the workflow cannot resolve the case, the NOC expert is brought in with full context

Key Components Used

  • A2A-T SDK — JSON-RPC communication between agents with Task-T Schema for deterministic task descriptions
  • Registry Center — Agent discovery via RAG retrieval matching complaint intent to available agents
  • Orchestration Center — Workflow canvas storing complaint handling patterns and execution logic
  • Authorization-T — Dynamic security ensuring agents only access appropriate network domains
  • Sub-Pub-T Eventing — Real-time network event subscription for proactive issue detection

Results & Benefits

60% Reduction in Resolution Time
45% Fewer Expert Escalations
85% Automated Diagnosis Rate
